Neon Shore Cover Maker — an offline web app that turns any photo and a caption into GTA-style poster cover art: multi-panel layouts, bold gradient lettering, sunset/neon colour grades, exported as a PNG in 1080×1080, 1080×1350 or 1920×1080. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
cd app && python3 -m http.server 8000
# open http://localhost:8000 in desktop Chrome, add photos, pick a layout, Export PNG
```

Add your own photos (or tap "Use sample photos"), click a photo then a panel to place it, drag panels to reposition, use the zoom/position sliders, edit the title, subtitle and badge, then export. Everything runs offline in the browser — photos never leave the machine. All art, lettering and sample photos are original works made for this app.
